# PRD: regtax-monitor — 법령 변경 모니터링 & 코드 반영 시스템

## 목표
세법·노동법 개정을 자동 수집·감지하고 eHR 코드의 수정 위치에 매핑, git apply 가능한 patch 초안까지 생성해 "개정을 놓치는" 리스크를 없앤다.

## 사용자
- 연말정산·급여 시스템(eHR) 유지보수 담당자 (1인 개발 → 회사 이식 예정)

## 핵심 기능
1. **수집·감지**: 법제처 API로 도메인별(세법 5종·노동법 11종, `domains.json`) 법령 3계층(법률/시행령/시행규칙) + 행정규칙(고시) 변경 자동 수집. 본문 빈 고시는 PDF 첨부 자동 추출.
2. **분석·요약**: LLM으로 변경 조문 요약·영향 분석. 업로드된 해설서(개정세법 해설 PDF) 발췌를 컨텍스트로 주입.
3. **코드 매핑**: RAG(bge-m3 + ChromaDB) + 용어 사전 정확매칭 + 상수 값매칭 3중 부트스트랩으로 관련 코드 위치를 Mapping으로 저장. 담당자 검증(verify)으로 매핑 자산 축적.
4. **patch 초안 생성**: 앵커 기반 편집 → unified diff. 골든 테스트(스크래치 사본)로 자동 검증. 사람 승인 게이트 통과 시에만 patch 파일 출력.

## 이번 범위에서 제외
- patch 자동 적용 (사람 승인 게이트가 최후 방어선 — 영구 제외)
- 구조 개정(공제 항목 신설·계산 체계 변경)의 초안 자동화 — 감지·알림까지만
- 세법 파라미터 테이블화 (로드맵 7 — eHR 리팩토링 수반, 장기)
- 과거 개정 커밋 few-shot 주입 (회사 repo 이식 후)

## 제약 조건
- **코드 반출 금지**: 기본(local) 모드에서 임베딩·검색·생성 전부 로컬. 외부 전송은 `LLM_BACKEND=claude` 옵션 경로에만 존재.
- 회사 PC: Python 3.10, SSL 프록시 환경(truststore 사용, verify=False 금지), 법제처 OC 키 target별 신청제.
- 비실시간 워크플로 — CPU 추론 수 분 소요 허용 (담당자 승인 대기 구조).
