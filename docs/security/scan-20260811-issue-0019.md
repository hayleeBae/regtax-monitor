## 점검했으나 이상 없음

- **캐시 코드 본문 유출 (CLAUDE.md 반출 금지) — 실측 검증**: fixture로 실제 `symbol_index_cache.json`을 생성해 문자열 검색한 결과 코드 본문 토큰(`findCredit(`·`long `·`return `·`public class`·`import ` 등) **0건**. 캐시 키는 `nodes`/`edges`/`skipped_files`뿐이고 노드는 `id`·`kind`·`name`·`path`·`container`만 담는다([symbol_index.py:676](app/embedding/symbol_index.py:676) `_to_dict`). 코드 본문은 노드 단계에서 애초에 저장하지 않는다.
- **캐시 gitignore**: `.gitignore`에 `symbol_index_cache.json` 등록(`git check-ignore` 확인). eHR 내부 구조(클래스·매퍼·관계) 파생물이라 커밋되면 반출 사고 — term_dict/const 캐시와 같은 취급.
- **EXCLUDED_DIRS 승격의 영향**: `RealCodebaseAdapter`에만 있던 목록을 `CodebaseAdapter`(base)로 올렸다. `RealCodebaseAdapter.EXCLUDED_DIRS`는 상속으로 그대로 해석돼 기존 참조·CLAUDE.md·`test_real_adapter_listing.py`가 불변(824 passed). `MockCodebaseAdapter.list_files`는 이제 빌드 디렉토리를 **제외**한다 — 보안적으로 **강화**(mock/집 경로에서도 산출물 심볼이 안 섞임). mock_repo에는 해당 디렉토리가 없어 기존 목록 불변.
- **경로 조작**: 심볼 경로는 `adapter.list_files()`가 준 상대 경로이며 사용자 입력이 들어가지 않는다. `_is_excluded`는 `path.parts` **구성요소 일치**(부분일치 아님)라 `outbound`·`buildings` 오제외 없음. `read_file`은 adapter가 담당(경로 검증·CP949).
- **입력 처리**: 외부 입력 지점 없음. 입력은 repo 소스 파일(adapter 경유). SQL 쿼리 생성·매퍼 변경 0건 — MyBatis XML은 **읽어서 statement id를 추출**할 뿐 실행하지 않는다.
- **인증/인가**: 신규 엔드포인트·라우트 0건. FastAPI·DB 미접근.
- **개인정보·로그**: 개인정보 경로 없음. 로그·예외에 파일 본문·절대경로를 담지 않는다(step 지시 준수 — "심볼 추출 실패로 건너뜀: <상대경로> (<예외타입>)"만).
- **시크릿·설정**: 하드코딩 시크릿·커밋된 `.env` 없음. 신규 설정 항목 0건. CORS·쿠키·디버그·TLS 무력화 변경 0건.
- **의존성**: `requirements.txt`의 pypdf 하한 변경은 `#0022`에서 온 것(origin/main 기준 diff에는 미포함). #0019는 신규 의존성 0.
- **fixture 반출**: `evaluation/fixtures/symbols/**`는 `com.example.*` 합성 코드 — 실제 eHR 코드·경로 없음. 커밋 대상으로 안전.
