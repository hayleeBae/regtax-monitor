## 점검했으나 이상 없음

- **정규식 안전성 (ReDoS)**: 신규 xfdl 패턴 3종(`_XFDL_SCRIPT`/`_XFDL_CDATA`/`_XFDL_FUNC`)과 `_JS_LINE` 전부 부정 문자클래스·lazy 매칭 기반, 중첩 수량자 없음. 중괄호 균형 탐색은 선형 문자 순회.
- **경로 처리**: `_is_excluded(path, root)`의 상대화는 `Path.relative_to`(예외 시 폴백)로 안전. `_scan_roots`의 `root / p` 결합은 운영자 소유 `.env`(`REPO_INDEX_PATHS`) 입력이며, 동일 신뢰 수준의 `REPO_ROOT`와 같은 경계 — 기존 `list_files()`가 이미 쓰던 패턴과 동일 해석. 외부(비운영자) 입력이 경로에 들어가는 지점 없음.
- **인코딩 변경의 보안 영향**: `utf-8-sig`/`cp949` 폴백은 데이터 해석 문제로 인젝션 표면 아님. `apply_patch`의 BOM 재부착은 바이트 상수(`\xef\xbb\xbf`) 고정 — 입력 유래 아님.

- **시크릿**: `git grep` 패턴 스캔 통과. 하드코딩·커밋된 `.env` 없음.
