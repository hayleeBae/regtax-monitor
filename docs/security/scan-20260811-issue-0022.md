## 점검했으나 이상 없음

- **외부 전송 게이트 (CLAUDE.md CRITICAL — 코드는 외부로 나가지 않는다)**: `runner._external_llm_allowed`는 **화이트리스트(default-deny)** 다 — `LLM_BACKEND=="local"`만 무조건 통과하고, 그 외(`claude`·빈 문자열·미지 값)는 `--allow-external-llm` 없이는 전부 False. 직접 probe로 확인: `("claude",0,False)→False`, `("",3,False)→False`, `("claude",3,True)→True`, `("local",3,False)→True`. 게이트는 `build_real_pipeline`·`run_fixtures`보다 **앞**에 있어 인덱싱·추론이 시작되기 전에 exit 2로 막는다. 경고 2줄(백엔드명·케이스 수)이 stderr로 나간다. `--pipeline stub`·local 경로는 외부 전송이 없어 게이트를 타지 않는다.
- **look-ahead 차단 (ADR-012)**: `real_pipeline`은 `VerifiedMappingProvider`를 구성하지 않고, reranker를 주입하지 않으며, `RetrievalConfig(rerank_enabled=False)`를 명시한다. DB 계층 import 0건(`test_source_has_no_database_imports`가 `app.db`·`sqlalchemy`·`Session`·`VerifiedMappingProvider`·`MappingDecision`·`get_session` 부재를 고정). 검증 매핑·결정 이력이 입력에 섞이지 않는다.
- **캐시 경로 격리·traversal**: `replay_index_key`는 sha256 hex(16자)라 경로 구분자가 나올 수 없고, 구성요소를 `\0`로 이어 경계 모호성을 없앤다. `replay_index_dir`은 `_SAFE_KEY=^[A-Za-z0-9_-]{1,128}$`로 키를 재검증해 `.`·`/`를 배제하므로 `..` 탈출이 불가능하다 — 상위 계층이 키를 잘못 만들어 넘겨도 `evaluation/replay_index/` 밖을 못 가리킨다.
- **운영 벡터DB 무접근**: `index_cache`·`real_pipeline` 어디에도 `./chroma_data`를 읽거나 쓰는 코드가 없다(주석 언급만). 어댑터·provider의 `repo_root`는 전부 `context.worktree`이며 `settings.repo_root`(오늘 코드)를 넘기지 않는다(`test_provider_and_adapter_repo_root_is_worktree`가 고정). `test_index_preparation_does_not_touch_operational_store`가 실행 후 `./chroma_data` mtime 불변을 확인한다.
- **회사 경로 유출 (CLAUDE.md 반출 금지)**: `_article_id`·`law_diff_text`는 경로를 넣지 않고 `case_id`·법령 텍스트만 쓴다(`test_law_diff_text_has_no_paths`). 검색 경고는 **본문 없이 건수만** 로그한다(provider 예외 메시지에 worktree 절대경로가 실릴 수 있어 의도적으로 뺌). `repo_id`는 runner가 해시로 만들어 캐시 키·리포트에 경로가 새지 않는다. 리포트 저장은 `#0018`의 `report.py` privacy 게이팅을 그대로 탄다(이번 변경 없음).
- **계층 경계 (ADR-012 보강)**: 생성 스택(`app.llm`) 의존은 `app/application/replay_draft.py`에만 있고 `app/evaluation/` 아래에는 없다 — `#0004` 계층 가드(`test_evaluation_layer_has_no_forbidden_imports`)가 통과한다(794 passed에 포함). runner는 `real_pipeline`·`replay_draft`를 파일 상단이 아니라 `--pipeline real` 분기 안에서만 지연 import(상단 import 목록으로 확인).
- **명령 실행·주입**: 이번 diff는 `subprocess`를 새로 호출하지 않는다. git은 `#0018`의 `git_cmd` wrapper를, 초안 생성은 `propose_and_build`(shell 없음)를 탄다. `draft_fn`은 문자열 조립 명령을 만들지 않는다.
- **입력 처리**: 새 외부 입력 지점은 fixture YAML(#0017 로더가 이미 검증)과 CLI 인자뿐. `--pipeline`은 `choices`로 제한, `--index-root`는 `_SAFE_KEY`가 하위 경로만 허용, `--allow-external-llm`은 store_true. SQL·매퍼 변경 0건.
- **인증/인가**: 신규 엔드포인트·라우트 0건. FastAPI·DB 미접근.
- **개인정보·로그**: 개인정보를 다루는 경로 없음. `draft_fn`은 스니펫을 로그하지 않는다(외부 전송은 게이트 소관). `logger.info`는 case_id·건수·불리언만 남긴다.
- **시크릿·설정**: 하드코딩 시크릿·커밋된 `.env` 없음. 신규 설정 항목 0건(`settings.llm_backend`는 기존 값 사용). CORS·쿠키·디버그·TLS 무력화 변경 0건.
- **인덱스 캐시 gitignore**: `evaluation/replay_index/`는 기존 `evaluation/` 하위 무시 규칙에 포함돼 커밋되지 않는다(대상 코드 임베딩이 담기는 반출 금지 자산).
- **의존성 변경**: `requirements.txt`/`requirements-dev.txt` 무변경. 발견 #1은 이번 변경과 무관.

## 점검 불가

- **CVE 등급 (발견 #1)**: 오프라인이라 PYSEC-2026-3655·3656의 심각도를 확인할 수 없다. 게이트 규칙 저촉 여부 미판정.
- **회사 환경 실동작**: 실제 eHR worktree 인덱싱 시 `evaluation/replay_index/` 디스크 사용량·소요 시간, `LLM_BACKEND` 실제 값은 회사에서만 확인 가능.

## 수용된 리스크 (사용자 확인 필요)

- **발견 #1 (미판정)**: `#0018`의 aiohttp/cryptography와 동일 패턴 — 이번 변경과 무관하나 게이트가 red다. 등급 확인 후 하한 상향을 별도로 처리.
- **local 백엔드가 아닐 때의 외부 전송**: `--allow-external-llm` 명시 시 스니펫이 외부로 나간다. 이는 사용자가 의도적으로 opt-in한 경우에만 발생하며, 게이트·경고가 그 앞을 막는다. 회사 환경 기본은 `LLM_BACKEND=local` 권장(런북 §4-2에 명시).
